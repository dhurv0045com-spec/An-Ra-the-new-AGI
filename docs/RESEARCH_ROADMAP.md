2. Qualify graph and rendering audits before training. Partition marked-root topology classes before rendering. The current variation concerns nuisance edges around two marked query paths. Keep a paired graph instance across nuisance shifts so effects are interpretable. Test duplicates, missing support and segment boundaries in intermediate copy math.
3. Run the owner-operated Colab screen for [H1/H2](HYPOTHESIS_REGISTER.md) after T4, device parity and persistence canaries pass. Keep an equal-exposure architecture comparison and score shifts by factor. Two seeds are sufficient for screening only. Inspect raw predictions, failure modes and cost before selecting the next campaign.
4. Review the complete Colab result and decide explicitly whether to run Kaggle. A positive screen can justify more seeds and structurally disjoint graph samples. The replication generator uses separately seeded, topology-disjoint instances from the same implementation. Screen and replication contain six development classes apiece, so cluster intervals have low resolution. Independent confirmation will require a separate generator, evaluator and custodian.
5. Use the causal follow-up that best discriminates the surviving explanation. If canonicalization alone wins, establish where its grammar assumptions break before generalizing. If raw augmentation wins, test a new renderer and unseen symbol inventory under an independent split. If recurrence alone wins deeper graphs, compare against more fixed reads and measure cost per solved pair. A measured sparse-copy advantage requires a dedicated same-semantics scaling probe.
6. Qualify two independent skill families before A→B→C. Compare scratch C, staged continuation, fixed replay and bounded memory or adapter strategies at matched cumulative cost. Require retention at frozen skill floors and a C learning-curve gain. Keep sealed evaluation, intervention approval and rollback under independent control.
7. Only after fixed strategies are measurable, test whether an adaptive policy selects better interventions than fixed, random and heuristic selectors. Record the true budget, held-out evidence, failed candidates and rollback identity. Owner review remains a separate decision.

## Decision discipline

- A blocked hardware canary means no campaign. An interrupted campaign supplies bounded partial evidence and remains incomplete.
- Report exact-plus-EOS answers, both-correct query pairs and latent-cluster counts. Multiple renderings and seeds reuse worlds. Estimate uncertainty at the independent cluster level.
- Use equal exposures for the primary model contrast and report measured time, read counts, memory and token usage separately. Distinguish fixed preprocessing from learned invariance and explicit depth cues from learned stopping.
- A negative screen redirects work toward the failing factor. It does not authorize more compute by itself. The next expansion must resolve an identified uncertainty within a frozen budget.
