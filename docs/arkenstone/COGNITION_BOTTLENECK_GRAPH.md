## Current causal picture

Demonstrated:

`ACQUIRED GENERAL CAPABILITY --(continued HIGH on some streams)--> instability`

`INSTABILITY --HIGH--> recovery more often than immediate LOW`

`RECOVERED --switch LOW--> lower recurrent instability`

`ORDER-INVARIANT BINDING --HIGH + canonical-only narrowing--> canonical skill retained, invariant eroded`

`ORDER-INVARIANT BINDING --LOW + canonical-only narrowing--> invariant retained`

`ORDER-INVARIANT BINDING --HIGH + continued order diversity--> invariant retained despite even larger parameter path`

Therefore the current best model is not "large updates are bad". It is an unresolved interaction between **plasticity/update scale** and **which capabilities the current data continues to support**.

Discovery V8 is designed to turn that statement into a causal mechanism and then into a bounded controller candidate.
