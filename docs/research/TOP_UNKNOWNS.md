## TOP 3 CRITICAL UNKNOWNS (forced reduction)

### U01 — the R1C mechanism question
- **QUESTION:** Is training-time inactive-class softmax competition sufficient (and partly necessary) for the class-space formation effect, independent of physical tied-matrix size?
- **WHY IT MATTERS:** it is the only mechanism-level hypothesis that could turn the program's largest discovery into a design rule; it decides whether the next Core changes its output space or keeps it frozen.
- **CURRENT EVIDENCE:** R1 isolated the declared class-space variable (V4096 100% vs V19 12.94% vs V24576 0%); R1B replicated the intermediate-regime ordering across 2 seeds; both leave competition vs tied-geometry vs init indistinguishable.
- **COMPETING EXPLANATIONS:** (1) inactive-partition competition; (2) tied embedding/output gradient burden; (3) initialization geometry of inactive rows; (4) seed-lottery amplitude modulation.
- **DECISION BLOCKED:** AD13 (vocabulary), AD15 (tied output), AD16 (softmax treatment), indirectly AD02 (500M rationale).
- **CHEAPEST DECISIVE EXPERIMENT:** execute the frozen CYR-GPU-014-R1C (its OFFSET_EQ4096 arm separates partition mass from gradient participation; dual structural/functional endpoints separate formation from calibration).
- **EXPECTED COMPUTE:** ~72,000 updates ≈ 22 T4-hours across sessions (multi-session exact-resume already designed).
- **FALSIFIERS:** mean paired AUC gap < 0.10 with no G50 advantage → competition not sufficient; structural-pass/functional-fail → calibration bottleneck; offset-arm rescue → partition mass alone suffices.
- **WHAT WE DO UNDER EACH RESULT:** dominant → output-space treatment becomes a production-candidate mechanism, EXP-2 runs with a mechanism arm; partial → mechanism search adds tied-geometry diagnostics to EXP-2; none → output-competition line killed (K01), EXP-2 becomes tied-geometry dissection.

### U02 — the Guardian validity question
- **QUESTION:** Does a dynamic escalation controller preserve an old skill while a new one forms, at strictly lower replay cost than matched static replay, without task-ID leakage?
- **WHY IT MATTERS:** it decides whether continual learning is a controller-research program or a static-replay calibration problem; it gates ARK-021 and every internalization claim.
- **CURRENT EVIDENCE:** V3.1 (in-repo, audited): controller recovery ≈0.963 vs static 0.882 vs plastic ≈0.005, but no prevention and no new-skill formation; V4 (transcribed): Guardian old 4/4 + new 4/4 at lower replay cost, static competitive — bundle not in repo.
- **COMPETING EXPLANATIONS:** (1) genuine anticipatory protection; (2) reactive dose escalation only; (3) static-replay equivalence; (4) task-ID leakage into controller features; (5) evaluation-timing artifacts.
- **DECISION BLOCKED:** AD21 (continual controller), internalization decision, ARK-021 design.
- **CHEAPEST DECISIVE EXPERIMENT:** bundle recovery + byte audit; if absent, a Guardian-vs-static matched contrast with task-ID-hidden features at the V4 dose.
- **EXPECTED COMPUTE:** 0 if bundle audits; ~6–9 T4-h if a rerun is needed.
- **FALSIFIERS:** bundle fails audit; Guardian does not beat static at matched retention when controller features are task-ID-hidden.
- **WHAT WE DO UNDER EACH RESULT:** confirmed → ARK-020 interpretation unlocks, ARK-021 is designed against the confirmed controller; refuted → controller line enters kill-criterion K02; static replay becomes the default protection with dose question U05.

### U03 — transfer of the class-space effect
- **QUESTION:** Does the class-space/representation formation effect persist at larger scale and under production-style tokenization (i.e., is vocabulary a 500M-blocking free parameter)?
- **WHY IT MATTERS:** if the effect is micro-arithmetic-specific, the production tokenizer is unblocked and the 500M data plan stands; if it transfers, the entire output-space design becomes evidence-gated.
- **CURRENT EVIDENCE:** effect exists only on 4L/128w arithmetic with active IDs fixed; ARK-001's whole-vocab null at micro lift-off suggests task/manipulation sensitivity; nothing tests scale or natural text.
- **COMPETING EXPLANATIONS:** (1) transfers; (2) micro-specific; (3) transfers only under the R1C mechanism (conditional on U01).
- **DECISION BLOCKED:** AD13/AD14 (tokenizer/vocabulary), the 500M data plan.
- **CHEAPEST DECISIVE EXPERIMENT:** CS-TRANSFER-001 (8L/256w matched V4096-vs-V24576 on (a) scaled arithmetic and (b) a clean production-tokenizer numeric-rendering task from the regenerated corpus surface).
- **EXPECTED COMPUTE:** ~12–16 T4-h.
- **FALSIFIERS:** formation gap < 0.10 at 8L/256w on both tasks → micro-specific (belief B07 falsified, production tokenizer stays default); gap present on arithmetic only → partial transfer, natural-text question escalates.
- **WHAT WE DO UNDER EACH RESULT:** transfers → vocabulary joins the 500M-critical path with the U01 mechanism in hand; micro-specific → tokenizer decision locked at default, representation research continues as science not as a 500M gate; arithmetic-only → design a cheap natural-text mini-probe before any tokenizer move.
