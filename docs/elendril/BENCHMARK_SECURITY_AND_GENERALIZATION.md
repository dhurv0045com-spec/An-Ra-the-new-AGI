# Benchmark security and generalization

ELD-DEV-004 creates independent RNG streams and disjoint unordered root-symbol groups before graph rendering. Every graph has two valid directed chains, distinct terminal values and independently shuffled facts. A one-hop oracle reaches a middle symbol and misses every base terminal. First/last/frequency controls cannot answer both queries. Edge rewiring preserves the prompt's token multiset and the queried first relation while changing the correct second destination. It is a stronger test than the neutral-query sanity control.

The benchmark keeps the model's inputs to prompt text and opaque correlation IDs. Greedy generation freezes predictions before joining evaluator labels. The published generator and verifier fixtures are development data. The current split still shares the path topology, length and template family between partitions. Sixteen development clusters are the units for uncertainty. The 64 pair views and three seeded learners reuse those clusters. Neither the views nor the seeds enlarge the graph population.

The post-hoc factor test shows that unfamiliar entity IDs and an unfamiliar separator can each disrupt the trained join. Freeze a next fixture with multiple graph topologies and two independently constructed renderers. Cross node and punctuation renaming independently. Include equal-depth distractors, swapped second-edge destinations, three-hop negative controls, query-neutral controls and omitted/ambiguous edges with a separately validated abstention contract. Split by a canonical graph representation after erasing superficial symbol names, then enforce exact and near overlap checks across renderers. An independent verifier should keep confirmation data separate and disclose only the evidence allowed by the preregistration.
