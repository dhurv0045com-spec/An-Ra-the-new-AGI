# ELD-DEV-004 frozen local development protocol

Does a differentiable second causal read help learn two-edge joins beyond a one-read associative head, contextual pointer-generator and near-parameter-matched dense control? The first copy distribution influences the second address through learned offsets and soft token matching. This is an explicit graph-join inductive bias. It uses prompt tokens and causal positions without parsing task syntax or receiving an intermediate label.

Each graph contains two queryable two-edge chains and a distractor. Edges are shuffled. Root-symbol pairs and RNG streams are disjoint between train and development. The development set contains 16 root-pair clusters, 64 graph views and 128 queries. Rewiring swaps the second destinations with the original slot order and token histogram preserved. Stress panels add a distractor, remap all symbols and the separator, or replace the graph with a three-edge version. Neutralization makes the two prompts in a pair identical. Oracle missing/ambiguous-edge behavior is tested separately. Those cases are not neural training endpoints.

Use CPU FP32, one thread, batch 16, seeds 7, 19 and 41. Run hybrid one-read, contextual pointer-generator and two-read for 384 updates. Run capacity-matched dense for 576 and compare its update-384 snapshot at equal exposure. Compare total training time against the nearest dense snapshot at updates 384, 480 or 576, with 10% relative tolerance. If outside tolerance report the cost/accuracy points without declaring time matching. Record parameter counts, actual costs, updates, matched exposure, prediction hashes and checkpoint identities. Stop on a failed contract, resource pressure or 180 seconds per process.

Primary formation requires 60% both-correct on base and 75% exact+EOS in every seed. Candidate advantage requires 20 points over all equal-update controls in every seed. Mechanism screen requires 50% both-correct on rewired and alias panels, 20 points of loss after removing the second read in the trained model, and zero both-correct under neutralization. Removing the second read changes the intervention-time distribution, so corroborate it with the input rewiring panel and direct joint scoring of base+rewire answers. Three-hop performance is exploratory. The retained endpoints are free-generation results. Development views are correlated within the 16 clusters. Precision and any architecture promotion require a separately frozen independent generator.

The contextual pointer baseline adapts pointer-generator mixing to a causal decoder. See, Liu and Manning published the original pointer-generator formulation for summarization. [ACL Anthology](https://aclanthology.org/P17-1099/).
