# ELD-DEV-003 frozen relational architecture comparison

ELD-DEV-002 isolated an architecture gain on a fixed two-fact rendering. This study asks whether that gain survives a near-exact parameter control and extends to new latent worlds, disjoint key symbols, and more distractors. Compare a tokenwise dense residual MLP, the hybrid read head, lexical-only addressing and contextual-only addressing. All methods share the same fresh dense weights, paired rows, CE plus counterfactual margin, schedule and generation cap. The dense MLP has six more trainable parameters than the hybrid model. The two ablations omit the removed projections or relation weights. They test component necessity under this budget.

Use the versioned relational-v1 fixture. Train on 352 rows with three facts, two separators, randomized fact order and 12 possible key symbols. A data cluster is an unordered triple of factual values. The primary development set has 96 rows from disjoint triples, with four different worlds per triple and two queried values per world. Alias substitutes entirely disjoint key symbols and a new separator. Two-fact and five-fact panels change distractor count while holding query and truth fixed. Neutralized query pairs share the exact prompt.

Use seeds 7, 19 and 41, 352 updates per arm, batch 16, eight complete exposure blocks, deterministic CPU FP32 and one thread. Freeze development scores at 0, 88, 176, 264 and 352, and score stress panels at 352. Use the same schedule and data for all arms. Run serially, stop on system pressure, nonfinite updates, contract failures or a 180-second process limit. Record actual wall time and sampled system memory. No official confirmation or sealed data is involved.

Primary formation requires 60% training and development both-correct and 75% development exact with valid EOS in each seed. For robustness require 60% both-correct in each alias and five-fact panel and zero on query neutralization. Test the architecture advantage as at least a 20-point gain over the capacity control in every seed on primary both-correct. For component attribution, compare hybrid against both ablations and report per-seed counts, including failure of the lexical gate on alias or fact-count changes. The study matches training data, exposure and updates. Timing is measured separately and cannot establish equal-FLOP superiority. Latent clusters and seeds remain the uncertainty units.
