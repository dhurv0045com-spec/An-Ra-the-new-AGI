# Elendril first implementation plan

This plan is derived from the repository [charter](ELENDRIL_MANDATE.md) and the supplied Codex master prompt. The separately named research plan was unavailable in the inspected checkout and download locations.

1. Pin Elendril's Cymek parent and crosswalk original evidence, contradictions and artifact custody.
2. Qualify a fresh-weight dense CPU reference with explicit answer and EOS supervision, real parameter updates and independently reproducible checkpoint continuation.
3. Build public development controls that expose world overlap, invalid EOS, query blindness, recency and metric floors.
4. Apply the frozen copy and binding learnability gates. If binding fails, use a read-only training-set diagnostic to separate acquisition and generalization before proposing a new intervention.
5. Prepare paired retention and compute-matched forward-transfer accounting. Execution depends on independent acquisition of the relevant skills and a globally disjoint task split.
6. Develop a prospective independent verification and rollback design for memory, weights and architecture. Reserve confirmation/sealed access, promotion, and expensive training for separate authorization.
