## DFC — the learning grammar

```text
state → constraint → hypothesis → prediction → check
  → observation → error → update → memory → next action
```

Frontier models mostly learn: `text → next token → plausible answer`.

An-Ra must learn: `change → constraint → test → update`.

`frontier_dfc.jsonl` encodes that chain. At 1B scale, **process** is the moat — not parameter count alone.

## Robotics & embodiment (vision, not fantasy)

Human-like autonomy is **two clocks**:

| Clock | Job |
|-------|-----|
| Fast (ms) | Motors, safety, reflexes — ROS / MCU |
| Slow (s) | Goals, planning, language — An-Ra |

An-Ra sends: “navigate to waypoint B.” The stack executes with estop and tier gates. The LLM does not run at 1 kHz.

Path: **sim → benchmark → hardware → audit**.
