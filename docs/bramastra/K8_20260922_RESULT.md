## Blocking finding

The generated bundle supplied **256 tool-training rows**. The frozen E3
protocol required 4,000 rows for `E3-T0-1701` and 3,000 rows for
`E3-T1-1702`. The ledger recorded these exact refusals:

```text
E3-T0 needs 4000 tool-training rows but only 256 exist; refusing to synthesize
E3-T1 needs 3000 tool-training rows but only 256 exist; refusing to synthesize
```

This is a preflight/data-planning defect. It is not a negative result about
tool learning, retention, cognition, or recursive improvement. The next run
must generate and validate enough distinct tool trajectories before GPU work
begins, using the frozen target plus the maximum replay requirement.
