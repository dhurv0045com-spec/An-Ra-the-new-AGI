- **Hardware adaptation after seeing science:** forbidden. Tier/proxy/dose resolution uses only fit, training real-token throughput, generation throughput, and wall budget before scientific outcomes.
- **Underpowered tier mistaken for production evidence:** every resolved plan carries `claim_ceiling`; TINY and retention-only tiers can never set `research_candidate=true`.
- **Two-parent variance:** two independent parents are the minimum replicated bar, not strong scale evidence. Three parents are preferred whenever affordable.
- **Evaluation cadence changes hysteresis behavior:** cadence is frozen by tier before outcomes; slow-GPU tiers still provide >=3 observations at dose floor.
- **LOW simply freezes learning:** displacement / optimizer-state diagnostics from inherited 006 machinery remain required; interpretation must separate engineering protection from consolidation mechanism claims.
- **Transfer confounded by age/exposure:** only equal-age/equal-exposure HYST-vs-LOW states from the same parent may enter transfer.
- **Cross-task forgetting:** fixed replay remains primary because ARK-013 already showed no-replay LR-only protection fails; 007 does not claim replay ratio optimality.
- **TINY proxy false generalization:** TINY is last-resort development only. Positive TINY evidence cannot authorize scheduler promotion or PRE500M.
- **Timebox survivor bias:** incomplete/timeboxed arms cannot enter a matched decision. Arm order remains counterbalanced by parent index.
- **Cell-0 calibration loss:** calibration JSON is written before resolution so even a resolver rejection returns useful hardware evidence.
- **Freeze drift:** executable/hash/dependency verification occurs after checkout of immutable Commit A and before calibration.
