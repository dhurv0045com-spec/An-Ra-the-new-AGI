## Verdict

**Architecture is not the primary bottleneck.** The primary bottlenecks are (1) the representation/output-space mechanism question — which is an *output-head/vocabulary* field, not a block design — and (2) data/evaluation readiness. Therefore the next Core is V5's architecture with locked contracts, evidence-corrected fields, and BLOCKED output-space fields, exactly as the candidate comparison formalizes. Per §7: DATA and EVALUATION dominate after representation; the architecture must consume a certified corpus and survive audited evaluation, and must not change blocks first.
