# Decision Record: Retirement of Ghost Memory and Legacy Web UI

Ghost Memory was an early experimental long-term memory substrate that attempted to persist cross-session conversational state via background file-based key-value stores. The legacy web UI was an un-authenticated prototype interface built for manual interaction before the unified Developer UI (`/developer`) and SFT prototype were introduced. Both systems were removed to simplify the codebase, eliminate unmaintained non-contract abstractions, and align the repository architecture around the canonical V4 model lineage, deterministic experience ledgers, and exact checkpoint resumability.

The retirement of the legacy web UI is permanent, as its operational capabilities have been fully superseded by the Developer UI and the SFT operator interface. The retirement of Ghost Memory is a structural deprecation awaiting potential replacement: while the unstructured file-based Ghost Memory store is permanently retired, structured session and long-term memory routing remain under active pilot via the unified experience ledger (`runtime/experience_ledger.py`) and memory router components once evidence-gated benchmarks warrant promotion.
