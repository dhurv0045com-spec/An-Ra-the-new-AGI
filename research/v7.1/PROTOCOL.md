# ELENDRIL V7.1 protocol

Status: **preregistered engineering and research design; no V7.1 GPU results yet**. Preserve V7 sources and receipts. The executable phase specification in `anra_v5/elendril/v71_protocol.py` and its hash bind the actual run; record any discrepancy or protocol amendment before inspecting results. The inherited V7 analysis reported a blocked mean of 80.4% across three seeds on the same 112 confirmation worlds, but only 10/48 blocked two-hop route outcomes. All nine final models queried 32/32 needed-query cases and abstained on 36/36 nulls, while unnecessary queries and seed-dependent value failures remained. The 336 model-case evaluations are not 336 independent worlds. Those observations motivate this study; **CAUSE UNRESOLVED** remains the starting point.

## Fixed phases

All seeds are 7, 19 and 41. The full declared phase is admitted or deferred as a unit; do not drop seeds, epochs, controls or difficult cases after seeing scores. Four-epoch core and scale runs use the same training data (seed 606, 2.2 MB target), architecture-specific settings and declared schedules; uniform and blocked refer to the qualified V7 orderings. Independent fresh initializations are used. The fixed phase matrix is:

| Phase | Jobs | Study |
| --- | ---: | --- |
| Core | 9 | S3 × three seeds × uniform CE, blocked CE, blocked intermediate supervision; four epochs each. |
| Scale | 12 | S8 and S20 × three seeds × uniform and blocked CE; four epochs each. Together with the six core CE jobs this is the 18-run S3/S8/S20 comparison. |
| Continual | 9 | S3 × three seeds × B-only continuation, B plus replay continuation, fresh-B baseline; two B-stage epochs. B-only and replay start from the corresponding blocked A checkpoint; fresh-B is independently initialized. |
| Frozen | Optional | No training jobs: evaluate eligible, verified V7 checkpoints only if their tensor files and identities are available. Otherwise report unavailable; do not substitute a fresh model and call it frozen V7. |

Intermediate supervision adds route actions and supervised targets; it also changes sequence/position exposure, optimizer work and compute. A difference from blocked CE cannot isolate the content of the intermediate target from those added resources. Report actual samples, targets, updates, positions and cost. The grammar-constrained decoder is a gold-free action-format control applied to frozen logits, not an independently trained pointer/copy architecture and not a replacement for raw neural decoding. Evaluate both and report their different decoding costs.

For continual learning, A is the prior missing-evidence and memory capability measured before transition; B is the independently generated 512-world three-hop training set (seed 27171). The replay branch adds 128 A worlds (256 supervised action samples) to the 512 B worlds/samples, for 640 worlds and 768 action samples; B-only has B alone. Replay therefore changes total exposure, ordering, optimizer updates and the learning-rate horizon, not just the presence of a memory mechanism. Report these separately and avoid a compute-matched claim. B's held-out three-hop score must be measured before B training: three-hop behavior may already be acquired. Retention is qualified only when the predefined 0.8 non-null threshold is met for the same model's old A before transition and new B afterward; otherwise report NOT_QUALIFIED rather than calling low later accuracy forgetting. Fresh-B is a baseline without parent A acquisition and cannot itself supply a retention claim. It runs even when the parent-A gate fails; A-initialized branches are then unqualified and skipped. Report A-before/A-after and B-before/B-after by seed. A genuinely novel C learning curve with a matched fresh baseline is deferred; the current design does not establish forward transfer.

## Evaluation and custody

Freeze the synthetic suite at seed 17071 and the reserved confirmation set independently of model outcomes. The default suite has 1,008 case records, including a 112-world V7-like base, 16 worlds for each 1–4-hop length, paired balanced payloads, intermediate-cue/sham and clamped-route pairs, memory manipulations, crossed query conditions, and template/row-order/distractor/alias variants. Cases share worlds across contrasts and must not be counted as independent replicates. Verify identities, semantic decision-state and world disjointness against actual training sets, and preserve the portable suite manifest and raw episode receipts. Independent generation means new deterministic sampling, not independent human authorship: the synthetic task family and AI authorship are shared, and this is not a sealed external evaluation.

Evaluate the base suite at epochs 1 and 2 and the complete stress suite at final checkpoints. Reserved confirmation is final-only and not used for selecting settings. Report non-null correctness, null abstention, query precision/recall and invalid actions, answer entropy, per-kind counts, both-correct counterfactual pairs, accuracy and confidence calibration with denominators, per-seed outcomes and matched paired changes. Keep engineered references explicitly distinct from neural models. Repricing the same fixed actions at query costs 0, 0.1, 0.5 and 1 describes utility sensitivity; the model never observes these costs, so it cannot demonstrate cost-conditioned adaptation.

The first-intermediate cue and equal-format sham are uninstructed extra rows and do not constitute injection of an internal state. The clamped condition instead changes the question to one hop from the correct first node while preserving the graph and final truth; it is an engineered decomposition, not the original prompt or proof of a mechanism. Memory-removed and irrelevant conditions deliberately retain the original target to measure availability effects; that target may then be publicly unsolvable, so abstention is scored incorrect there and must not be interpreted as a safety failure. In stale-corrected memory, a later same-source row corrects an earlier wrong row. Compare the raw behaviors, not aggregate accuracies alone.

Owner authorization permits a **330-minute maximum session**; it does not guarantee the full matrix fits. Before each phase, use production-shaped training, evaluation and recovery probes on both T4s to conservatively estimate its complete wall time, memory and overhead, including exports. Admit only the whole phase if the bound fits the remaining budget; otherwise defer it. Preserve partial outputs and failure receipts if an admitted run fails. GPU availability and reproducibility require actual canaries, source and model identities, optimizer/checkpoint recovery and replay checks; no GPU result is claimed before execution. Record actual updates, supervised tokens, unpadded and padded positions, attention pairs, memory, wall time and reservations. Equal data and updates do not imply equal padded compute or wall time. No data-scaling factorial, pointer model, or novel-C study is silently added.
