## Launch

Upload `notebooks/ELENDRIL_V71_KAGGLE_T4X2.ipynb` to Kaggle. Enable **GPU T4 ×2** and **Internet**. Leave `RUN_STUDY=True`, `PHASE='core'`, `MINUTES=330`, and the input paths unset; Run All fetches the exact immutable Git commit, uses native PyTorch, generates the data in `/kaggle/working`, audits disjointness, and runs admission canaries. No manually attached data is needed for core or scale. The read-only `/kaggle/input` mount is not a download destination.

Core runs nine four-epoch jobs: S3 uniform CE, blocked CE, and blocked with intermediate supervision, each at seeds 7/19/41. Epochs 1/2 retain base and three-hop evaluations; final epoch 4 retains all 1,120 diagnostic records, including the 112 reserved confirmation worlds. Every final checkpoint also receives gold-free grammar decoding. Worlds recur across interventions, so 1,120 records are not independent worlds. CPU data qualification reproduced the original 7,335-world/9,472-sample training identity; intermediate supervision has 12,264 samples and 3,068 updates over four epochs, versus ordinary CE's 2,368 updates.

The **scale** phase independently runs all twelve S8/S20 CE jobs. Together with the six core CE jobs this supplies the suggested 18-run size/curriculum matrix. The **continual** phase needs the saved V7.1 core FULL archive; set `PARENT_ARCHIVE` to its Kaggle input path and change `PHASE`. It runs nine B-only/replay/fresh-B branches, gated on measured old-skill acquisition. B has 512 worlds/512 supervised examples; replay adds 128 A worlds/256 action examples, for 640 worlds/768 samples. Its additional compute, ordering and schedule confounds are recorded. A failure of the acquisition gate is NOT_QUALIFIED, not a forgetting result. A novel-C forward-transfer learning curve remains deferred.

The optional **frozen** phase needs the original V7 FULL ZIP from the audited source `413a3eccf4344ef2a39051b870e92feb6271b769`, not its analysis-only ZIP. It reevaluates all nine historical final weight generations with both decoders and preserves their original identities. That archive has not been supplied locally; this phase's actual checkpoint compatibility remains owner-required. It makes no original optimizer-continuation claim.

Only the selected whole phase is admitted. Positive learning and exact recovery canaries run separately on both GPUs; production-shaped probes for each selected size/mechanism supply a forecast with 2× timing headroom and export reserve. A phase that cannot fit returns a clear NO_GO/PARTIAL decision, rather than reducing its seeds or epochs. Scale requires at least 19 GiB free and may be deferred on an occupied Kaggle volume. A timing estimate is not a guarantee against service interruptions or hardware variation.

## Save, resume and return

Download **ELENDRIL_V71_ANALYSIS.zip**, **ELENDRIL_V71_FULL.zip**, and **FINAL_STATUS.json** from the notebook links or saved Kaggle output. Checkpoints and reports are saved incrementally; an analysis snapshot is attempted after every completed job. Both archives are rebuilt and verified at the end, including failed or partial runs.

Same-session Run All resumes the same source/phase output without overwriting historical receipts. For another session, attach the saved FULL ZIP, set `RESTORE_ARCHIVE` to its input path, and retain exactly the same notebook source/phase. Extraction verifies names, sizes, SHA values, CRCs and readback, with a 16 GiB uncompressed ceiling; it requires a new destination and sufficient disk. After extraction, clear the archive setting for any subsequent same-session retry. An uncommitted extraction marker requires inspection; its directory is never silently reused. A parent archive is likewise extracted into a separate new directory; later retries select it explicitly via `PARENT_OUTPUT`. Runtime/identity mismatch is rejected, not silently migrated. Same-device fresh-process exact recovery has CPU regression coverage; fresh-VM GPU recovery remains unqualified until actually exercised.

Completion requires every registered final report, mandatory intermediate reports, matched grammar results, independently replayed actions, both current-run ZIPs and verified checkpoint components. It means engineering delivery, not scientific success. The report starts at **CAUSE UNRESOLVED**. Grammar effects concern output constraints, confidence bins are descriptive, cost changes only reprice fixed actions, and memory tests include deliberately unanswerable availability interventions. No pointer architecture, learned price policy, sealed independent benchmark, AGI result or self-improvement claim is supplied.
