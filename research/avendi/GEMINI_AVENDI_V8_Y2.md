## Scientific decision

I would spend the first session locating the **first point where a changed question stops changing the predicted value**. Across three Y1 F11 seeds, changing the queried chain produced the identical token sequence 767 times in 768 pairs. This result has a known counterfactual. By comparison, the timestamp heuristic scored perfectly on the old primary, so the primary score alone could never resolve traversal. The underlying problem may be weak entity selection, weak composition, low answer probability or an uninformative training distribution. Each points to a different intervention.

Make **a complete counterfactual family** the unit of scientific success. First demonstrate correct lookup on two keys. Then ask if the same elementary transition can be reused and deliberately redirected in mid-computation. Finally test whether correcting one mistaken transition improves behavior on new examples without damaging previously learned behavior. These steps span representation, weights and adaptive state while preserving separate causal contrasts. The deliverable for the first notebook is a decision about the first failing dependency. Later studies have separate admissions and budgets.

For opaque/incomplete worlds verify the set of possible answers given public evidence. Two completions yielding different endpoints witness ambiguity. ## P3 — one attributable learning intervention

Hypothesis: forcing the correct value to outrank the rival when only the query or a bridge changes creates usable discrimination. Use fresh S3 initialization shared within seed pairs to isolate acquisition. Retain the byte decoder and native Y1 tokenizer. Six jobs: CE and CE+pair margin × seeds 7/19/41. Seed separately by purpose. Use one fixed corpus seed 2201 and common epoch-zero tensors, family schedule and held-out sets. Train on 1,024 distinct one-hop families × four cells = 4,096 decision states. Four shuffled epochs, batch 16 = four whole families per update, 1,024 updates. Grouped gradient accumulation microbatch 4, identical in both arms. All answer targets include EOS. Since the action is always appropriate this stage isolates acquisition of lookup.

Use Y1 S3 profile (3,084,800 parameters, width 256, four blocks, 512 context), FP32 AdamW historical parameter groups, betas (.9,.95), epsilon 1e-8, weight decay .1, clip 1, cosine LR 1e-4→1e-5, no warmup. For each cell i set signed margin s_i = first-byte gold logit minus rival endpoint logit. Loss = mean eligible-token CE + λ mean(max(0,1−s_i)); λ=0 or 0.25. Use identical full four-cell batches. Audit both objective gradient norms on shared logits and eligible counts at update 1. Changing the arm to X1 at this step would change architecture and output coding together. Negative control swaps the auxiliary pair labels on a tiny gradient fixture and must reverse the signed auxiliary update. Record train and dev monitor of 64 fixed families each at updates 0,64,256,512,1024. Sealed families do not enter monitors.

Support requires ≥10 pp mean complete-family gain, positive in each seed, ≥80% one-hop all-four in every treatment seed on confirmation, and no >5 pp same-seed literal drop. If both qualify equally, use CE for the simpler qualified operation. If both memorize but fail held-out lookup, test held-out role permutations and cue conflict before modifying architecture. If neither fits the training monitor, inspect optimizer/gradients and a 32-family overfit fixture. Preserve negative outcomes. Freshness, coverage and scaling are separate later contrasts; varying them in P3 would defeat attribution.

## P4 — exchanging a learned intermediate state

**Why this could work.** If a learned transition implements “current symbol → bound value”, reusing it should support a new path length, and replacing the current symbol should predictably redirect the remaining computation. A black-box decoder can learn this too. The intervention tests whether a particular intermediate state has the proposed causal role.

Implement a new small controlled model using the exact same public observations. For each rendered row obtain learned key/value vectors from a shared encoder with explicit row boundaries; record that the boundary parser supplies structure. Map the current 16-way state to a query embedding; softmax attention over row keys gives weights; weighted row value representations project to a 16-way next-state distribution. Initialize state as the public query one-hot, share transition weights at all steps, expose the public hop count as the repeat count. Read final state directly through a fixed A–P mapping; separate interactive action selection belongs to P5. No original-query skip, step-dependent position predictor, unrestricted recurrent cache, or separate path from whole graph to final readout. Broad soft distributions can encode covert information; repeat the swap test with hard argmax one-hot state at inference and disclose the soft/hard accuracy change.

Architecture lock: byte embedding width 64; independently encode each row using a shared one-layer GRU(64,64) over its public row bytes, final row vector mapped by separate affine key/value projections of width 64. Learn 16×64 state embedding, dot-product attention divided by 8, shared 64→16 output. Row order receives no independent embedding. Use terminal CE only by default. Controls: (a) same row encoding and repeated attention with a learned 64-dimensional continuous recurrent state and a final 16-way readout, (b) one-step attention readout with same row encoder, (c) analytic public oracle. Same examples, optimizer, seeds and update schedule as P3 except 512 one-hop + 512 two-hop families per epoch; withhold three/four hops. Fit compute estimates on the measured lengths; report parameter counts, multiply-add estimates, padded positions, wall time and memory. Match width/control parameters within 10% when possible by a preregistered CPU width search over 48,56,64,72,80 for the continuous state, choose closest, tie smaller. Report residual differences. The one-step control has intrinsically less computation. A separate intermediate-supervision arm is deferred until a terminal-only failure; charge every extra label.

**Interchange protocol.** Run two queries on the same graph, select a fixed cut immediately after transition 1. Cache the entire carried state. Continue A using B's state with the same graph and remaining horizon; do the reverse. Predict the exact donor endpoint independently. Record both directions on all families, baseline correctness, initially both-correct subset size, donor success unconditional and conditional, sign/magnitude of endpoint log-odds shift and per-layer state entropy. Controls: no swap, identity state replacement, different donor on a third chain with known distinct endpoint (extended grammar), random permuted state, row-encoder perturbation of matched norm, and an oracle one-hot intermediate. Vary downstream terminal edges **after** the cut and ask whether the donor-routed prediction follows the new terminal. This last test distinguishes portable intermediate entity from simply caching the donor's final answer. To make it decisive, encode prefix transitions using the original graph, recompute row representations for suffix graph in both swapped and unswapped controls, and ensure edits touch neither prefix edge. Run a matched suffix-unchanged control. No oracle labels enter ordinary inference.

Admit neural interchange interpretation only with ≥80% raw three-hop all-four on the unedited test in each seed, ≥128 eligible both-correct families per seed, identity swap ≤1 pp drop and correct donor-specific outcomes ≥80% conditional **and** ≥70% unconditional on both suffix conditions. Require positive donor-specific excess versus permuted state in every seed. Distinguish intervention evidence within this architecture from improvements versus continuous-state control. An architectural advantage additionally needs ≥10 pp average four-cell gain and positive differences every seed against that control on held-out depth. If oracle intervention works but learned exchange fails, inspect state identity/alignment; if oracle intervention also fails, inspect suffix readout and horizon. If only the soft state succeeds, test whether information survives projection to a symbol; defer an “editable symbol” claim.

## P6 — bounded correction that must transfer

Build paired conventions with identical pre-feedback observations and opposite targets. A single informative feedback case disambiguates the convention; test 16 unseen graphs with fresh symbols per block, plus 16 old-convention retention cases in the old context. Fix 128 blocks, balance convention, evaluate the same blocks in every arm. New entity bindings prevent caching a single answer. Record performance separately for all assigned blocks and blocks with an initial genuine error to avoid selection bias.

Reset identical checkpoint/environment state at each block. Compare (1) frozen, matched extra forward pass, (2) same model with true external feedback in context, (3) same length irrelevant feedback, (4) wrong feedback, (5) true feedback written into a persistent two-slot convention memory, presented later after clearing the original dialogue, (6) one bounded gradient step on the same feedback, cloned model, reset optimizer, LR 1e-5, clip 1, (7) same step with irrelevant feedback, (8) self-generated candidate correction chosen by predicting the outcomes of two **publicly available** calibration actions and checking one observed outcome, matched to an external-feedback arm with the same observation and calls. If no informative observation is made available, two symmetric conventions are indistinguishable; honest expectation is chance. Record who chose each action, who produced each label, state changed, bytes written, model calls and gradient steps. A scripted two-hypothesis verifier is an engineered ceiling. To claim self-directed correction the **model** must select an informative calibration action over an equally available uninformative one and apply the resulting correction in new problems. Expose the complete action log.

Support for transferable correction requires ≥15 pp held-out gain versus matched-compute and irrelevant-feedback controls, positive every seed, ≤5 pp old-context loss, and performance following the assigned convention in both directions. Matched external improvement alone qualifies feedback use. Memory persisting after dialogue clear qualifies context-indexed adaptation. Rerun after resetting that memory to establish dependence. For sequential weight preservation first measure standalone A and B ≥80% each per seed, then compare acquired A→B with A→A and joint A/B at equal updates and monitor both tasks. Record error detection, information choice, correction accuracy, transfer and retention separately. An improvement in the update algorithm itself would require a future independently controlled second-order experiment. P6 is outside the first notebook budget.

## Implementation details that affect interpretation

**A computable odds test.** Treat g as the original endpoint of query A. For cell signs (+,−,−,+), a positive interaction can coexist with three incorrect cells. Publish the four signed margins and the minimum. Call a “latent flip” only when all four signed margins exceed zero. When greedy answers repeat, report how many such families still have four flips, and how often the raw winning token was Q, R, ! or a malformed output. Retain the new odds results even if a qualification gate fails.

**Bind the adapted task to real inputs.** For legacy models serialize the crossed graphs with the actual Y1 native renderer and evaluate raw byte generation under original EOS semantics. For P4 use precisely those same rendered facts, parsed into rows, in both learned encoders. Attach no row labels for key, terminal, path membership or evidence relevance. The state index learned from terminal CE can have an arbitrary internal permutation. Interpret swaps between native donor/recipient states directly. For oracle injection, report fixed public-symbol injection and, separately, a bijection fitted only on training/calibration data, frozen before test. Failure of unaligned public one-hot injection alone cannot establish broken downstream reasoning. Compare swapping states within a graph with donors from *different* independently relabeled graphs that represent the same public entity, where support permits. Success within one graph and failure across graphs would delimit portability.

**Coverage of literal and secondary panels.** Generate 256 literal cases as 16 answers × 16 balanced distractor contexts (“return the symbol in the marked register”), randomizing register location, public tick and nonanswer content; keep the native action prefix. Treat literal performance as sensitive to instruction familiarity; if it fails while native lookup passes, mark the literal test format-sensitive and proceed from demonstrated lookup. The acquisition corpus uses unique one-hop base families. During the optional P4 training phase use 1,024 matched family groups per epoch as specified. Evaluate in the original native syntax first; each transfer variant gets its own denominator. Retain all first-failure diagnostics when a whole arm misses the seed gate.

**When the optional correction study is admitted.** Use two explicit public operators L and R, with conventional meanings “read the left field” and “read the right field”. Each record contains distinct field values. Regime 0 uses the ordinary mapping; regime 1 swaps it. Establish both mappings separately with an explicit context cue first. In correction blocks omit that cue, place the same ambiguous support graph under each regime, and balance gold marginals. Calibration actions expose the consequence of applying a named operator to either an informative record with unequal fields or an uninformative one with equal fields. The choice itself must precede observation. In the current convention two candidate strategy strings describe the two mappings. A memory arm can select/write one of these strings and later read it with equal context length in placebo arms. Log whether the selection was model-generated or externally chosen. Define error detection as predicting an error before feedback, score Brier against a constant-rate control fitted on dev. Post-feedback recognition alone cannot establish prospective error detection. Reserve a disjoint bank of support records, mapping assignments and transfer graphs for confirmation; reset all adaptation between blocks. These decisions make an external correction usable as positive control even if self-directed information collection fails.
