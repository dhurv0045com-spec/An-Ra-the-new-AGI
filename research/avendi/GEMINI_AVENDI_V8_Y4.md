**Primary question.** Given two distinct chains, can a model trained only on one and two steps follow a novel three- or four-step chain, and does switching its current entity change the result in exactly the way the recipient graph predicts? The decisive comparison trains two identical categorical models on different meanings for the same state intervention. One gets the true counterfactual target, one gets a balanced sham. The clean supervised categorical model is an additional comparator. A sham can damage learning, so a win over the sham alone earns no mechanism credit.

**Secondary question.** Does that gain survive when the model has to find the rows in public bytes? A model furnished with structured rows, a step count and a built-in value copier answers a different question. Publish separate results for byte grounding, learning the transition and composing it. A third experiment asks whether a learned policy can identify which missing fact is worth acquiring when no prompt field tells it the condition.

Record the common-corpus limitation. Case count is never the model sample size.
2. Build functional graphs from two **vertex-disjoint** paths of depth d. Select two query keys, two distinct endpoints and disjoint internal nodes without replacement. Swap the two starting edges to change the answer and reverse row presentation independently. Each family has 2 queries × 2 assignments × 2 orders. Allow optional disconnected edges and incoming branches with fresh keys. Every public key has one successor; include no timestamp cue. Publish depth explicitly when comparing fixed-step solvers, and evaluate a separate variable-stop diagnostic with an observable terminal marker. A changed terminal, an irrelevant rewire and randomized timestamps each get a separate panel. Canonicalize parent graphs before variants. Group relabelings and surface variants by ancestral family, reserve graph/role combinations and grammar templates for transfer, audit semantic role tuples, exact byte prefixes and full decision histories across splits. With fixed tiny motifs report topology reuse explicitly. Use independently sampled meaningful background structure to support the requested distinct pools. If capacity is insufficient, expand the entity namespace with uniformly tokenized two-byte IDs before registry freeze, rerun collision and tokenizer audits and use the same encoding in all matched arms. No seed-based assertion of disjointness.
3. Independently parse the **tokenized public observation** (decode and reparse, no hidden edges, labels or generator traversal). Follow the unique successor d times. Check every native, reordered, patched and transfer cell. Require full agreement, unique asked paths and distinct gold/rival in every crossover cell. Example d3: rows A→C→E→G and B→D→F→H. Queries produce G/H, swapped starts H/G, either row order. Prefix identifies neither answer. Mask the queried key or required bridge to produce identical public bytes with opposing answers. Exact walker must pass 8/8, balanced first/last-row, timestamp, prior, query-blind, terminal-copy, masked-bridge and always-abstain baselines must fail full-family qualification. Test all-zero rows, ambiguous/missing successors and padding as invalid inputs. On typed models check permutation and padding invariance against unpadded single-case execution.
4. Training sets have 1,024 families per new core world, 512 each at d1/d2 for composition. At eval use **256 families per depth per panel**: train-like unseen instances, row/timestamp nuisance, entity bijection, distractor, held-out topology (reserve merges outside the queried path; train with disconnected distractors), and held-out renderer; report each axis and their joint transfer separately. Public-byte models see the rendered prefix only. Typed controls receive independently parsed public rows. Typed scores are invariant to a semantics-preserving renderer by construction; mark that cell as a parser check. For byte-to-typed bridge, train the parser on training-only entity/role labels, evaluate exact parse and use oracle/learned parser × oracle/learned executor on identical cases. Report unconditional scores plus scores conditioned on a correct parse. Literal readout uses 256 families × four positions × two wordings, with gold first-byte rank, competing logit margins, action class and EOS failure.
5. P5 uses 1,024 training families and 256 per held-out condition in each split. Conditions are sufficient, required-obtainable, required-unobtainable, irrelevant-missing, newly relevant, newly irrelevant, stale/contradictory. Hide these names from the actor. Balance answer labels, row positions and tool flags within feasible matched strata. Show the same available tools on matched worlds that require opposite decisions. Query/retrieve returns only an interior edge, never an endpoint token. Run the response through the policy for the terminal answer, with a fresh irrelevant response of equal format and length as control. Costs 0.10 query/0.05 retrieve, answer +1 correct/−2 wrong, abstain 0, horizon one paid tool action then answer/abstain. Use public known reliabilities and prior, enumerate latent worlds consistent with public history, update by Bayes. Compute V(b)=max of terminal values and −cost+Σ_o p(o|b,a)V_terminal(b_o); forbid unavailable actions. Sample effectful and ineffective tools. Enumerate an independent scalar oracle and compare vectorized values on every finite fixture to ≤1e−8, including ties, high-cost no-tool and zero-probability observations. Use optimal-action sets. Expose costs/reliabilities to actor and oracle equally.
6. P6 uses two equiprobable public candidate laws with distinct outputs on at least two inputs and one indistinguishable input. Generate 1,024 training and 256 dev/confirm/transfer law-pair blocks per split with disjoint law-pair IDs. Randomize alternative order, symbol aliases, test input and menu arrangement. Balance which law is active by paired worlds, hold the pre-feedback observation fixed, score on a distinct disagreement input. Correct feedback disambiguates; irrelevant evidence leaves the posterior unchanged; incorrect evidence points at the competing law. Keep the actor blinded to feedback assignment. Mirror twins at each stratum. No-info Bayes accuracy = 0.5; noiseless informative upper bound = 1.0. Use the same exact Bellman solver, allowing passive and forced alternatives, to compute expected utility under optimal downstream decisions. Separately measure realized utility using the model downstream. Give both mechanisms access to the same public input and forbid all probe truths during adaptation.
