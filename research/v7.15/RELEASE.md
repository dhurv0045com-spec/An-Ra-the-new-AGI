## Diagnostic experiments and attribution

The V7.15 frozen diagnostic suite combines:

- 512 paired route-surface records, crossing same-world timestamp ranges, clutter presence and row serialization across two-hop, first-hop, clamped and direct lookup questions. Changing the question is a new task, not an internal-state clamp.
- 384 anti-shortcut one- to four-hop records over 16 shared worlds: original, reversed, shifted time, removed/replaced distractors and removal of a required edge. The obvious last-row and maximum-timestamp copying rules are deliberately prevented from solving the original examples.
- 96 matched memory records: original, equal-length consistent repetition, stale-then-correct, reversed correction order, absent memory and irrelevant memory. Memory removal changes what is publicly knowable; abstention is the appropriate outcome.
- 96 query-availability and 32 balanced counterfactual payload records from the original audited V7.1 generator. Test action legality and evidence-responsive behavior, keeping engineered grammar effects separate.

These are **1,120 case records from related synthetic worlds, not 1,120 independent populations**. They are development diagnostics, not independently authored sealed test results. Only genuine raw neural behavior is attributed to the model; the grammar constrained decoder and procedural teacher are engineered references.

The frozen worker checks every checkpoint generation, trained source identity, S3 spec/tokenizer, finite tensors, exact weight fingerprints, evaluation/report binding and unchanged weights after inference. The campaign requires all nine models, both decoder reports and an independently replayable analysis archive before reporting COMPLETE. If anything fails, it emits partial receipts and NO_GO status.
