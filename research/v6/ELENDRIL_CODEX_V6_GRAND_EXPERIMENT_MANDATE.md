## V. FROZEN SCIENTIFIC EVALUATION
Implement the 15 panels exactly as registry names, preserve additions separately:
- **P01 Positive-control learnability:** Can a neural model fit explicit QUERY+EOS before OOD tests? Record train loss; exact content+EOS; invalid tokens. Gate: Always run; training prompts and distinct validation shown.
- **P02 Known-evidence answering:** Does it answer immediately when evidence is sufficient? Record correct; redundant query count; calibration. Gate: Always after P01; matched seen/unseen worlds.
- **P03 Missing-evidence query:** Does it request useful evidence when facts are missing? Record query precision/recall; terminal accuracy; cost. Gate: Always after P01.
- **P04 Conflicting-evidence query:** Does it avoid unsafe answers under unresolved conflicts? Record query rate; wrong-answer rate; later resolution. Gate: Always after P01.
- **P05 Null and unavailable abstention:** Does it distinguish explicit null vs unavailable evidence? Record ABSTAIN accuracy; invalid actions; utility. Gate: Always after P01.
- **P06 Post-query revision:** Can it incorporate a newly received observation and change its answer? Record end-to-end episode accuracy; intervention sensitivity. Gate: Always after P01.
- **P07 Cost-aware thinking and queries:** Is it better than always-query, never-query and fixed? Record utility; requests; cost/quality Pareto. Gate: Always after P01.
- **P08 Uncertainty and self-error detection:** Does pre-outcome confidence predict error on novel worlds? Record Brier; ECE; AUROC; accuracy/coverage; extra cost. Gate: Diagnostic only; fitting/calibration uses separate validation.
- **P09 Legal action and EOS integrity:** Does it emit parseable actions and terminate exactly? Record exact+EOS; malformed outputs; loops; abstentions. Gate: Always; raw outputs never repaired.
- **P10 Query swap and query blindness:** Does answer causally follow query, not a constant shortcut? Record paired both-correct; input intervention effect. Gate: Always; paired latent worlds.
- **P11 Temporal/recency shortcuts:** Does it respect timestamps and provenance over text order? Record counterfactual pair accuracy; recency control. Gate: Always; time/source intervention pairs.
- **P12 Representation and distractor OOD:** Does performance survive aliases, separators, new templates and distractors? Record separate/joint OOD accuracy; loss; failure clusters. Gate: Always; independent generator; do not train on sealed variants.
- **P13 Compositional reasoning 2→3 hop:** Does the learned core generalize beyond action tokens and 2-hop joins? Record exact graph pair; 3-hop; shortcut controls. Gate: Conditional on qualified route/graph task; otherwise NOT_QUALIFIED.
- **P14 Frozen-weight memory benefit:** Can admitted memory improve new episodes without a weight update? Record memory on/off; retrieval choice; cost; causal swaps. Gate: Conditional on available compatible learned or frozen model; provenance separate.
- **P15 Sequential retention and transfer:** Does A survive B, and does B accelerate unseen C at equal total work? Record A-before/after; B; C curves; total GPU work. Gate: Conditional on independently qualified A and B; otherwise NOT_QUALIFIED.

The **primary endpoint** is full-episode utility = exact terminal correctness - 0.1 × verified queries; independently report model token/position/call budget and wall time.
