# Planthir Universal Research Infrastructure — Validation Reports

This directory stores curated Tier-1 scientific reports and provenance-bound summary metrics generated by `anra_v5.planthir`:

- **`EXP_PLANTHIR_001_FAULT_CALIBRATION.md` & `EXP_PLANTHIR_001_METRICS.json`** — Controlled 6-fault injection calibration suite + direct before/after verification of the `anra_v5/elendril/v8/evaluation.py` consumed-tool bug (`enforce_tool_consumption=True` vs `False`).
- **`EXP_PLANTHIR_002_CAUSAL_DIAGNOSTIC_VALIDATION.md` & `EXP_PLANTHIR_002_METRICS.json`** — Bounded CPU end-to-end validation (`<= 100k` parameters, `6` updates/arm) across all six V8 architecture controls (`B0`, `J`, `F`, `P`, `F-cap`, `U`), exercising `PlanthirRegistry`, `CheckpointCatalog` zero-retraining restore/diff, `InternalTelemetryCollector`, 4-stage `ProcessFunnelAnalyzer`, all 4 causal counterfactual interventions, epistemic-firewalled `synthesize_scientific_interpretation`, and SHA-256-verified Tier-2 capsule offline linear probing.
- **`EXP_PLANTHIR_003_HISTORICAL_SYNTHESIS.md` & `EXP_PLANTHIR_003_METRICS.json`** — Data-driven longitudinal historical synthesis across `Experiment Result/V6` through `Experiment Result/V8`.
- **`EXP_PLANTHIR_004_LIVE_GPU_VALIDATION.md`, `EXP_PLANTHIR_004_METRICS.json` & `AI_HANDOFF_BRIEF.json`** — Live `NVIDIA GeForce RTX 4050 Laptop GPU` validation of the Level-5 5-Gate `ExperimentCartridge` pipeline (`J`, `F`, `P`, `U`, `92k–121k` params, `60` updates/arm, `75.56 MB` peak VRAM), verifying milestone trajectory probing, surgical mechanism ablation, compute depth scaling, `result.zip` (`4.06 MB`) + `checkpoint_full.zip` (`12.04 MB`) live-vs-restored parity (`1.000`), and token-minimal AI handoff (`~82%` estimated token reduction).
- **`REGISTRY_SNAPSHOT.json`** — Content-addressed `PlanthirRegistry` snapshot for registered validation runs.

**Curation & Storage Policy:** Consistent with `AGENTS.md`, only lightweight Tier-1 Markdown reports and summary JSON artifacts live here under Git. During runs (including `EXP-PLANTHIR-002` and `EXP-PLANTHIR-004` in temporary directories), `export_result_bundle()` also builds self-describing `FINAL_STATUS.json`, `CHECKPOINT_INDEX.json`, `RESULT_OVERVIEW.md`, compact `result.zip` (`<= 20 MB`, bundling Tier-1 results, Tier-2 capsules, and full checkpoints or `float16` `model_fp16.bin` weights), and whole-store `checkpoint_full.zip` — excluded from Git via `.gitignore` and directly loadable via `CheckpointCatalog.load_from_result_zip()` and `CheckpointCatalog.restore_full_checkpoint_zip()`.

Reproduce current Level-7 verification checks and inspect/verify bundles via (see [`orchestrator_agent.md`](../../orchestrator_agent.md), [`execution_agent.md`](../../execution_agent.md), and [`agent.md`](../../agent.md) for current workflows; `run-validation-study` and `run-gpu-validation` are preserved as historical Python APIs while CLI automation uses `schema` / `init` / `validate` / `run`):

```bash
python -m anra_v5.palantiri level
python -m anra_v5.palantiri doctor
python -m anra_v5.palantiri calibrate
python -m anra_v5.palantiri shield
python -m anra_v5.palantiri verify-bundle --bundle-dir <bundle_dir>
python -m anra_v5.palantiri verify-archive --archive <session_zip>
```
